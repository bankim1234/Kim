# Data Analyzer

A simple application that allows users to upload CSV data and automatically analyze it.

## Features

- Upload CSV files
- Display uploaded data
- Count rows and columns
- Detect missing values
- Calculate:
  - Average
  - Minimum
  - Maximum
  - Count
  - Statistical summaries
- Analyze numerical data
- Analyze categorical data
- Display charts
